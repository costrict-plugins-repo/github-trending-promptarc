---
description: Share the current session to the cloud as a private replay. Builds the artifact locally, redacts secrets, uploads directly.
---

Run `promptarc share <session-id>` to share a session to the cloud.

If promptarc is not installed globally, use `npx -y promptarc share <session-id>`.

The session ID can be found by running `promptarc context`. You can use just the first 8 characters.
